Interview met een klasgenoot

Ik heb het interview met Mustafa gedaan.

1. Waarom heb je gekozen voor Software Developer?

Ik vind computers en games interessant en ik wilde leren hoe je zelf apps en websites maakt.

2. Wat vind je het leukste aan de opleiding?

Het leukste vind ik als mijn code werkt. Dan zie ik meteen wat ik zelf gemaakt heb.

3. Wat vind je het moeilijkste?

Fouten in mijn code vinden. Soms zit er maar één klein foutje in en dan duurt het lang voordat ik het zie.

4. Kon je al een beetje programmeren voordat je begon?

Een heel klein beetje. Ik had wel eens iets geprobeerd, maar het meeste leer ik pas nu.

5. Wat wil je later doen als developer?

Ik wil later bij een bedrijf werken waar ik aan echte projecten kan werken.
